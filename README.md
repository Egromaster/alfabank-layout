# Alfa-Bank Layout

Учебная вёрстка главной страницы Альфа-Банка по предоставленному макету.

## Стек

- HTML5 (семантическая разметка)
- CSS3 (Grid, Flexbox, custom properties, медиа-запросы)
- Vanilla JavaScript (для табов и интерактива)
- Без фреймворков и бандлеров

## Структура

```
.
├── index.html
├── css/
│   ├── reset.css       # Josh Comeau's modern CSS reset
│   ├── variables.css   # CSS custom properties (цвета, шрифты, отступы)
│   ├── fonts.css       # @font-face декларации
│   └── style.css       # основные стили
├── js/
│   └── main.js         # табы, интерактив
└── assets/
    ├── images/         # иллюстрации блоков
    ├── icons/          # иконки
    └── fonts/          # локальные шрифты
```

## Реализованные блоки

- [x] 1. Hero (Альфа-Вклад 22%, кредитка, инвестиции, кредит наличными, Альфа-Карта)
- [x] 2. «Выбирайте лучшее» (табы + сетка продуктов)
- [x] 3. Кэшбэк-баннер
- [x] 4. «Сервисы» (курсы валют + список услуг)
- [x] 5. «Пользуйтесь выгодными предложениями» (табы Альфа-Мобайл и т.д.)
- [x] 6. «О банке» (работодатель, банк, отзывы)

## Адаптив

Поддерживаемые брейкпоинты: 1920px → 1440px → 1024px → 768px → 360px.

## Запуск

Открой `index.html` в браузере. Сборка не требуется.
